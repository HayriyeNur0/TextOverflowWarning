## Amaç

TFT ekranda metnin kendisine ayrılan genişliği (Width)
aşıp aşmadığını tespit eden bir uyarı sistemi geliştirmek.

## Girdiler

- Text
- Font
- Area Width

## Çıktı

Fonksiyon True/False döndürmez.

Fonksiyon;

text_width - area_width

değerini döndürür.

Sonuç;

> 0  → Yazı taşıyor.

= 0  → Yazı alana tam sığıyor.

< 0  → Yazı alana sığıyor.
